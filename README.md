# Lean4Tutorial

Lean4Tutorial is a Lean 4 and mathlib project for learning how to formalize mathematical proofs from economics papers. At this stage it contains only the minimal library files generated by Lake's official `math` template and reproducible setup tooling.

## What is pinned and what is installed on the machine

Git, curl, Elan, and an editor are machine-level prerequisites. Elan is Lean's toolchain manager. Inside this repository, `lean-toolchain` selects the exact Lean release, while Lake uses `lakefile.toml` and `lake-manifest.json` to obtain the project's pinned dependencies. A global Lean installation is neither needed nor recommended.

## Fast setup on macOS

After cloning the repository, run:

```bash
./scripts/bootstrap.sh
```

The script checks Git and curl, installs Elan with Lean's official installer if necessary, makes `$HOME/.elan/bin` available for the current run, checks the editor integration, downloads the mathlib cache, and builds the project. It does not use sudo or install Homebrew.

## Prerequisites and manual setup

macOS includes curl. Git is available after installing Apple's Command Line Tools:

```bash
xcode-select --install
```

Install Elan using the [official Lean installation method](https://lean-lang.org/install/):

```bash
curl https://elan.lean-lang.org/elan-init.sh -sSf | sh
source "$HOME/.elan/env"
```

Then, from the repository root, reproduce the project setup without changing its dependency pins:

```bash
lake exe cache get
lake build
```

`lake exe cache get` downloads precompiled mathlib artifacts, avoiding a lengthy source build. On a fresh checkout, Lake uses the committed manifest to obtain the pinned dependency revisions as part of these commands.

## VS Code

Install [Visual Studio Code for macOS](https://code.visualstudio.com/docs/setup/mac), then install the official `Lean 4` extension (`leanprover.lean4`), published by Lean FRO. With the `code` command available, this is:

```bash
code --install-extension leanprover.lean4
```

If VS Code is installed but `code` is unavailable, open the Command Palette and select **Shell Command: Install 'code' command in PATH**. The repository's `.vscode/extensions.json` also recommends the extension when the folder is opened.

## Project files and tools

- **Elan** installs and selects Lean toolchains.
- **`lean-toolchain`** pins the Lean version selected by Elan for this repository.
- **Lake** is Lean's project and dependency manager.
- **`lakefile.toml`** declares the `Lean4Tutorial` library and its mathlib dependency.
- **`lake-manifest.json`** records exact resolved dependency revisions for reproducible checkouts.
- **`lake exe cache get`** obtains precompiled mathlib build artifacts matching those revisions.

Commit both `lean-toolchain` and `lake-manifest.json`. Running `lake update` later may change pinned dependency revisions, so do it only as a deliberate dependency upgrade and review the resulting manifest changes.

## Check and build

Report the local environment and verify the build:

```bash
./scripts/check-environment.sh
```

Build directly at any time with:

```bash
lake build
```

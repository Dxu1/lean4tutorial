# Mortensen--Pissarides (1994) in Lean 4

This directory formalizes the theoretical core of Dale T. Mortensen and
Christopher A. Pissarides, "Job Creation and Job Destruction in the Theory of
Unemployment," *Review of Economic Studies* 61 (1994), 397--415.

## Files

- `Definitions.lean`: primitives, matching technology, asset-value predicates,
  the reduced steady-state equations, gross flows, and dynamic accounting.
- `Equilibrium.lean`: value-function, reduced steady-state, two-state, Markov,
  and simulation-path equilibrium structures.
- `Results.lean`: machine-checked derivations and comparative-static helpers.
- `Verification.lean`: build-time checks that every result is free of `sorry`.
- `../i002_replicate_MP.lean`: entry point for building the full formalization.
- `Mortensen-JobCreationJob-1994.pdf`: source paper supplied by the user.

## Notation

The Lean identifiers intentionally follow the paper:

| Lean/paper symbol | Meaning |
|---|---|
| `r` | discount rate |
| `λ` | Poisson arrival rate of job-specific shocks |
| `σ` | dispersion of job-specific productivity |
| `β` | worker's share of match surplus |
| `c` | vacancy flow cost |
| `b` | unemployment income or value of leisure |
| `p` | aggregate productivity component |
| `εu`, `εd` | upper shock support and destruction cutoff |
| `dF`, `F` | shock probability measure and its CDF |
| `q`, `m`, `θ` | vacancy meeting rate, matching flow, and market tightness |
| `V`, `U`, `J`, `W`, `w`, `S` | vacancy, unemployment, firm, worker, wage, and surplus values |
| `u`, `v`, `n` | unemployment, vacancies, and employment |
| `C`, `D`, `N` | creation flow, destruction flow, and period employment |

## Paper-to-Lean map

| Paper | Lean declaration |
|---|---|
| (1) vacancy value | `Primitives.VacancyBellman` |
| (2) free entry | `Primitives.FreeEntry` |
| (3) surplus | `Primitives.SurplusIdentity` |
| (4) Nash sharing | `Primitives.NashSharing` |
| (5)--(6) filled job/worker values | `FilledJobBellman`, `WorkerBellman` |
| (7) unemployment value | `UnemployedBellman` |
| (8) surplus Bellman equation | `SurplusBellman` |
| (10) job destruction | `JobDestructionCondition` |
| (11) σ response | `dispersionCutoffResponse` |
| (12) surplus slope | `S_cutoff` |
| (13) job creation | `JobCreationCondition` |
| (14) Beveridge curve | `BeveridgeCondition` |
| (15) unemployment dynamics | `unemploymentDrift` |
| (20), (24) anticipated destruction | `BoomDestructionCondition`, `RecessionDestructionCondition` |
| (29), (30) anticipated boom surplus/creation | `boomSurplus`, `BoomJobCreationCondition` |
| (32)--(34) Markov equilibrium | `GeneralMarkovValueEquilibrium` |
| (36)--(38) simulated flows/accounting | `periodCreation`, `periodDestruction`, `nextEmployment`, `SimulationPath` |

The static equations use the CDF generated by a Lean `Measure ℝ`; the paper's
Stieltjes continuation integrals are represented directly as expectations with
respect to that measure.  Section 5's numerical calibration is empirical rather
than a theoretical result and is not re-run here, but its equilibrium and
accounting interfaces are included.

## Verified results

Among the theorems in `Results.lean` are:

- Nash shares exhaust match surplus;
- equations (3)--(7) imply the match-surplus Bellman equation (8), and firm
  value is zero at the destruction cutoff;
- equation (13) is equivalent to zero-profit free entry;
- the JC locus slopes down;
- the equation (11) σ response is positive under the paper's stated
  net-price condition;
- a higher cutoff raises the destruction hazard;
- equation (14) makes gross creation equal gross destruction and sets the
  equation (15) unemployment drift to zero;
- positive aggregate shocks generate opposite creation/destruction movements;
- σ shocks generate same-direction movements;
- equation (30) reduces to equation (13) when aggregate transitions are shut
  off, and anticipation strictly reduces boom θ for fixed cutoffs;
- recession-only immediate scrapping makes short-run destruction exceed its
  ongoing component;
- the period employment change equals creation minus destruction.

## Build

From the repository root:

```sh
lake build Lean4Tutorial.i002_replicate_MP
lake build
```

The first command is the dedicated MP1994 validation target.  It compiles the
definitions, equilibrium structures, results, and explicit no-`sorry` audit,
without importing `Lean4Tutorial.basic_examples`.  The second command builds
the complete tutorial library; its root module also imports the MP1994 entry
point, so it validates the formalization as part of the full build.

## Readable mathematical audit

The human-readable rendering of the Lean development is available as:

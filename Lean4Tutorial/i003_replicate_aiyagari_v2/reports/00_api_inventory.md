## Architecture preflight

The unbounded state and bounded value-function type coexist and have the needed complete metric. `ENNReal` can retain an infinite boundary marginal: `extended_zero_value` proves the type admits a function with value infinity at zero. It does not construct a value derivative or claim marginal finiteness. Differentiation remains on real-domain extensions as designed.

Normalized `(R,w,k)` coordinates are real data independent of the debt shift `phi`; no type-level dependency requires the raw debt limit to stay bounded. The approved natural-limit substitution `k = -w*l_min` can therefore use bounded normalized parameters when wages stay bounded while `phi` diverges. This is a representation assessment, not a newly formalized economic identity; price records and economic admissibility are reserved for milestone 01 and later. No type incompatibility was found.

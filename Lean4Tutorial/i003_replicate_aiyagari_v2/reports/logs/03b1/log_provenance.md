# M03B1 log provenance

All final logs in this directory were generated in the existing pinned local environment on
2026-09-12, after the H09 implementation and manifest/ledger synchronization. No network,
external model, dependency update, staging, commit, or manual review archive was used.

`targeted_build.log`, `full_build.log`, `audit.log`, `signatures.log`, `contracts.log`, and
`docs_build.log` are direct command outputs. `assert_no_sorry.log` inventories the M03B1
assertions that completed in the direct audit. `transitive_axioms.log` is extracted from that
audit. `prohibited_patterns.log` records the comment-stripped project-wide scan. Source and
artifact hashes, the baseline scope check, and PDF rendering metadata are separately recorded.

The two untracked files shown one directory above this project by `git status` pre-existed this
run and were not read, changed, packaged, or otherwise used.
